# 📚 Base de Conhecimento — Suporte Técnico N1

Procedimentos para os problemas mais comuns no atendimento ao usuário em ambientes Windows 10/11, organizados como em uma base de conhecimento real de service desk.

Os artigos de **atendimento** (01 a 08) seguem sempre o mesmo padrão:

1. **Sintomas**: o que o usuário relata
2. **Perguntas iniciais**: o que perguntar antes de mexer em qualquer coisa
3. **Diagnóstico**: do teste mais simples ao mais complexo
4. **Solução**: o que resolve cada causa
5. **Quando escalar**: o limite do atendimento N1
6. **Registro no chamado**: o que anotar

Os artigos de **procedimento** (09 a 11) são guias passo a passo para tarefas de manutenção.

## Princípio que uso em todos os atendimentos

> Começar pelo simples, mudar uma coisa de cada vez e anotar o que foi feito.

Antes de TI, trabalhei com manutenção mecânica. Lá aprendi que trocar peças "no chute" custa caro e não ensina nada. Em suporte vale o mesmo: confirmar o sintoma, isolar a causa e só então aplicar a solução, deixando tudo registrado para quem pegar o próximo chamado.
